# Hamdy Arkoub Personal Website

This is a GitHub Pages-ready personal academic website for Hamdy Arkoub.

## How to publish

1. Create a new public repository on GitHub named:

   `HamdyArkoub.github.io`

2. Upload all files in this folder to the repository:

   - `index.html`
   - `assets/style.css`
   - `assets/script.js`
   - `README.md`

3. Go to repository **Settings → Pages**.

4. Under **Build and deployment**, choose:

   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`

5. Save. The website should be available at:

   `https://HamdyArkoub.github.io`

## Things to customize

- Replace the Google Scholar, ORCID, and LinkedIn links in `index.html`.
- Replace the HA placeholder with a professional photo if desired.
- Add a `cv.pdf` file and link it from the website.
- Add research images or simulation figures later.
